Rental Board

Connect this phone to your private rental-hunter repo. You only do this once per device.

You've opened the board from your home screen. iPhone keeps home-screen apps separate from Safari, so connect once more here. After that it opens straight to your board.

  1. On github.com: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → rental-hunter.
  3. Permissions: Contents → Read and write. Generate, then copy it.

The token stays in this browser only. It can read and change the rental-hunter repo and nothing else.
